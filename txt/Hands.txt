Hands can be used to play a certain Poker Hand during a round to gain score and beat blinds. A run will fail if all hands in one round are used while the score requirement is not met.

Most decks start each run with 4 hands per round. Note that the player will always start each round with at least 1 hand, even when combining effects that would reduce the amount of hands to 0 or lower.

First hand triggers

[edit | edit source]

The following Jokers and Blinds only trigger on first hand played.

Jokers

[edit | edit source]

-  (If {{hl|orange|first hand}} of round has only {{hl|orange|1}} card, add a permanent copy to deck and draw it to {{hl|orange|hand}} Rare Effect On Played DNA.png)[] DNA creates a permanent copy of a selected playing card if first hand in round contains only 1 card.
-  (If {{hl|orange|first hand}} of round is a single {{hl|orange|6}}, destroy it and create a {{Spectral|}} card <br> {{room}} Uncommon Effect N/A (Passive) Sixth_Sense.png)[] Sixth Sense creates a Spectral card and destroys the selected playing card if first hand contains a single playing card with a rank of 6.

Blinds

[edit | edit source]

-  ( Boss The Mouth.webp)[] The Mouth forces the player to keep playing the first hand type they played in the round.

[edit | edit source]
