Effect

Limitation varies per deck.

Unlock Requirement

Challenge Mode is unlocked by winning a regular run with five different decks.

Challenge Decks are unique decks that contain some condition making them unique from, and often more challenging than, the normal decks. This could manifest in having an altered starting deck, possessing certain (Can't be sold or destroyed Sticker Eternal Sticker.png)[][] Eternal Jokers, restrictions on hands or discards, restrictions on allowed cards, and more. They can only be played on the ( White stake.png)[] White Stake.

When playing Challenge Decks, achievements and unlocks cannot be obtained, as some would be trivialized by the conditions given by the deck. Statistics such as the number of times a consumable has been used and high scores like Best Hand/Highest Ante still get updated. It is not possible to start a seeded run on Challenge Decks, but the seed generated by each challenge run can still be used on normal decks.

Decks

[edit | edit source]

There are twenty different Challenge Decks currently in Balatro, with the first five unlocked after winning on five different decks. Each subsequent deck is unlocked after winning a run with a new Challenge Deck. To unlock all the Challenge Decks, the player needs to win with fifteen of them.

Trivia

[edit | edit source]

- The card back of the Challenge Deck is a maze. The maze can be started either from the top opening or the bottom one.
- LocalThunk, the developer of Balatro, has stated that some manner of challenge creator is on his list of things to add, with no timetable.
- If a Challenge begins with a Voucher, and a saved run is continued from the main menu before the first Blind is selected, any effect the Voucher would have will not be applied.
