# 结算与提现界面坐标

横屏 2400x1080, 坐标直接用于 `input tap`.

## 盲注结算界面 (打完达标的一手牌后自动出现)

| 元素 | 值 |
| --- | --- |
| 结算面板范围 | 840, 200 - 1900, 1080 |
| 继续 (点击点) | **(1283, 760)** |
| 已验证 | 是 |

面板内容: 盲注图标, "至少得分" 与分数线, 奖励金额.
面板上任意位置点击都能继续, 取面板中央偏下最稳.

## 提现界面 (Cash Out)

| 元素 | 包围盒 | 点击点 | 已验证 |
| --- | --- | --- | --- |
| 提现按钮 | 1253, 398 - 1837, 490 | **(1545, 444)** | 是 |
| 明细面板 | 840, 360 - 1726, 1080 | 不需点 | - |

明细逐行列出收入, 常见条目:

| 条目 | 说明 |
| --- | --- |
| 盲注奖励 | 小盲注 $3, 大盲注 $4, Boss $5, Showdown $8 |
| 剩余出牌次数 | 每次 $1, 会显示 "2 剩余出牌次数 (每次$1)" 这样的行 |
| 利息 | 每 $5 持有金钱给 $1, 上限 $5 |
| 小丑牌效果 | Egg, Golden Joker, Rocket 等回合结束效果 |

## 界面流转变换

完整的一次循环:

```text
主游戏 → (打完达标一手, 自动) → 结算面板 → 点 (1283, 760)
      → 提现界面 → 点 (1545, 444)
      → 商店 → 点 (939, 439) 下一个回合
      → 下一场盲注 (主游戏)
```

每步之间都有动画, 点击间隔建议 2-3 秒:

```shell
adb -s <serial> shell input tap 1283 760 && sleep 3
adb -s <serial> shell input tap 1545 444 && sleep 3
```

## 判读技巧

- 结算面板出现的标志: 画面中央出现大块深色圆角面板, 左侧 "回合分数" 数值已更新.
- 提现界面的标志: 顶部有橙色 "提现: $N" 按钮.
- 商店的标志: 左上角出现 "SHOP" 霓虹招牌.
- 每次切换后重新截图确认, 不要盲连点三次 (动画未结束时点击会落到空白处, 白白浪费一个动作).
