## 手牌区

手牌数量变化时整排牌重新居中, 因此这里给的是公式而不是固定表.

```text
点第 i 张牌 (1-based, 共 N 张):
  x = 1220 + (i - (N + 1) / 2) * s
  y = 690
  s ≈ 130   (N ≥ 5)
  s ≈ 137   (N ≤ 4)
```

| 项 | 值 |
| --- | --- |
| 手牌区纵向范围 | y 约 620-840 |
| 建议点击 y | 690 |
| 排布中心 x | 约 1220 |
| 相邻间距 | 约 130 px |
| 单张牌宽 | 约 130 px |
| 选中后抬起位移 | 约向上 44 px |

8 张牌时的实测点击点:

| 序号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| x | 768 | 898 | 1027 | 1156 | 1285 | 1414 | 1543 | 1672 |

其中第 1, 2, 3 与第 7, 8 张已实际点击验证.

3 张牌时实测索引位置约 1080, 1220, 1354, 与公式一致.

### 选中状态判读

同一列在点击前后的"卡牌顶部边缘 y"会相差约 44 px, 可用来确认是否真的选中:

```python
import numpy as np
from PIL import Image

def top_edge(path, x, y0=520, y1=900):
    a = np.asarray(Image.open(path).convert('RGB')).astype(int)
    col = a[y0:y1, x]
    light = (col[:, 0] > 170) & (col[:, 1] > 165) & (col[:, 2] > 150)
    idx = np.flatnonzero(light)
    return int(idx[0] + y0) if idx else None
```

注意: 选中牌时右上角会弹出 "梅花3 / +3筹码" 之类的浮动提示框, 它也是浅色, 会让采样列误判.
采样列要选在卡牌左侧索引角附近 (例如牌中心减 55 px), 或避开 y 300-420 的提示框区域.
