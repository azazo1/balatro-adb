# 无尽模式与附录

## 无尽模式 (Endless Mode)

- 击败底注 8 的 Showdown 盲注后, 一局即算通关. 此时可以选择结束, 或继续进入无尽模式.
- 无尽模式从底注 9 开始, 底注没有上限, 每 8 个底注 (16, 24, 32 ...) 出现一次 Showdown 盲注.
- 底注 9 之后分数要求按几何级数暴涨 (公式见 [盲注与标签](08-blinds-and-tags.md)),
  到接近数值上限时会因浮点溢出显示为 `naneinf`.
- 无尽模式的目标是刷新个人最高分, 通常需要依赖乘算倍率的连锁 (例如蓝图 / 头脑风暴复制倍率类小丑牌,
  配合红色蜡封重触发与牌型等级).

## 术语表

| 术语 | 含义 |
| --- | --- |
| 底注 (Ante) | 一局的进度单位, 每个底注含小盲注, 大盲注与 Boss 盲注 |
| 盲注 (Blind) | 一场需要达标的挑战, 达标后可以进入商店 |
| 回合 (Round) | 一场盲注内的实际操作阶段, 有出牌与弃牌次数限制 |
| 筹码 (Chips) | 计分公式的左半部分 |
| 倍率 (Mult) | 计分公式的右半部分, 分为加算 (+Mult) 与乘算 (XMult) |
| 手牌上限 (Hand Size) | 手牌持有的目标张数, 默认 8 |
| 出牌 (Hand) | 打出一组牌, 消耗一次出牌次数 |
| 弃牌 (Discard) | 丢掉一组牌换取新牌, 消耗一次弃牌次数 |
| 伪弃牌 (Pseudo-discard) | 用少于 5 张的牌型把手里的杂牌顺带打出去 |
| 小丑牌 (Joker) | 放在小丑槽里的持续效果卡 |
| 消耗品 (Consumable) | 塔罗牌, 星球牌, 幻灵牌的统称 |
| 补充包 (Booster Pack) | 商店中可购买的开包商品 |
| 优惠券 (Voucher) | 商店中的永久增益, 有基础版与升级版 |
| 标签 (Tag) | 跳过小盲注或大盲注获得的奖励 |
| 增强 (Enhancement) | 扑克牌上的特殊效果, 如玻璃, 钢铁, 石头 |
| 版本 (Edition) | 闪箔, 全息, 多彩, 负面 |
| 蜡封 (Seal) | 红色, 蓝色, 金色, 紫色 |
| 贴纸 (Sticker) | 永恒, 易腐, 租用, 以及通关记录用的赌注贴纸 |
| 失效 (Debuff) | 卡牌被禁用, 不计分也不触发 |
| 重触发 (Retrigger) | 让一张牌的效果再触发一次, 多次重触发相加 |
| 赌注 (Stake) | 同一牌组上的难度等级, 白到金共 8 级 |
| 成长 (Scaling) | 小丑牌随回合或操作永久提升数值 |

## 数据来源与完整性

- 所有规则, 数值与列表来自社区维护的 [Balatro Wiki](https://balatrowiki.org/), 对应版本 **1.0.1o-FULL** (Friends of Jimbo 4),
  抓取时间 **2026-09-29**.
- 本手册的口径是 **1.0.1o-FULL**. 其他版本 (例如移动端的 1.0.0L) 存在差异, 已知差异见
  [version-diff.md](../version-diff.md), 其中包含 13 张小丑牌价格,
  5 张稀有度以及疯狂小丑, 聪慧小丑, 旗帜等效果数值的不同.
- 卡牌的中文名是依效果意译的; 游戏的官方简体中文名可用安装包内的 `localization/zh_CN.lua` 替换,
  也可用 [scripts/extract_apk_game_data.py](../../scripts/extract_apk_game_data.py) 直接提取带官方中文名的数据表.
- 原始页面保存在 [raw/](../../raw/), 可检索的纯文本保存在 [txt/](../../txt/), 提炼出的结构化表格保存在 [data/](../../data/).
- 表格数据由 [scripts/extract_tables.py](../../scripts/extract_tables.py) 从原始页面提取,
  与手册中的表格内容一致, 便于程序化检索与后续更新; [scripts/check_docs.py](../../scripts/check_docs.py) 负责校验条目完整性.
- 手册覆盖了计分机制, 牌型, 卡牌修饰, 150 张小丑牌, 52 张消耗品 (22 张塔罗, 12 张星球, 18 张幻灵),
  15 种牌组, 8 个赌注, 20 个挑战, 商店与经济, 34 个盲注与 24 个标签. 未逐一展开的内容包括: 各小丑牌的具体解锁条件 (见 `data/Jokers.1.csv`),
  成就与幻灵包的细节差异 (例如 Illusion 优惠券当前版本无法让商店扑克牌带蜡封, 属于已知缺陷), 以及本地化译名的官方版本.
