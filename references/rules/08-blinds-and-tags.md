# 盲注与标签

## 盲注的分数要求

每个底注由小盲注, 大盲注, Boss 盲注组成; 底注 8 (以及无尽模式的 16, 24, 32 ...) 的 Boss 盲注是 Showdown 盲注.

| 盲注 | 分数要求 |
| --- | --- |
| 小盲注 | 基础分 x1 |
| 大盲注 | 基础分 x1.5 |
| Boss 盲注 | 基础分 x2 (The Wall 为 x4, Violet Vessel 为 x6, The Needle 为 x1) |
| Showdown 盲注 | 与 Boss 盲注相同 |

基础分随底注增长, 且绿赌注与紫赌注会加快增长速度 (等离子牌组把所有要求再翻倍):

| 底注 | 基础分 | 绿赌注及以上 | 紫赌注及以上 |
| --- | --- | --- | --- |
| 0 及以下 | 100 | 100 | 100 |
| 1 (起始) | 300 | 300 | 300 |
| 2 | 800 | 900 | 1,000 |
| 3 | 2,000 | 2,600 | 3,200 |
| 4 | 5,000 | 8,000 | 9,000 |
| 5 | 11,000 | 20,000 | 25,000 |
| 6 | 20,000 | 36,000 | 60,000 |
| 7 | 35,000 | 60,000 | 110,000 |
| 8 (Showdown) | 50,000 | 100,000 | 200,000 |
| 9 | 110,000 | 230,000 | 460,000 |
| 10 | 560,000 | 1,100,000 | 2,200,000 |
| 11 | 7,200,000 | 14,000,000 | 29,000,000 |
| 12 | 300,000,000 | 600,000,000 | 1,200,000,000 |
| 13 | 4.7e10 | 9.4e10 | 1.8e11 |
| 14 | 2.9e13 | 5.8e13 | 1.1e14 |
| 15 | 7.7e16 | 1.5e17 | 3.0e17 |
| 16 (Showdown) | 8.6e20 | 1.7e21 | 3.4e21 |

继续往上: 17 至 38 底注的基础分依次为 4.2e25, 9.2e30, 9.2e36, 4.3e43, 9.7e50, 1.0e59, 5.8e67,
1.6e77 (底注 24, Showdown), 2.4e87, 1.9e98, 8.4e109, 2.0e122, 2.7e135, 2.1e149, 9.9e163,
2.7e179 (底注 32, Showdown), 4.4e195, 4.4e212, 2.8e230, 1.1e249, 2.7e268, 4.5e288.
底注 39 的要求为 4.8e309, 会因数值溢出显示为 `naneinf`.

底注 9 及之后的分数要求由公式生成后保留两位有效数字:

```text
requirement = ante8_requirement * (1.6 + (0.75 * (ante - 8)) ^ (1 + 0.2 * (ante - 8))) ^ (ante - 8)
```

底注 0 只能通过圣书体 (底注 -1) 配合优惠券标签等特殊操作达成; 底注 -1 则需要额外的操作 (同时拿到圣书体与岩画).

## 盲注一览

Boss 盲注随机出现, 每个 Boss 都有自己的最低底注要求, 并且遵循 "出现次数最少的优先" 规则,
也就是一个 Boss 不会在其他 Boss 都出现一次之前重复出现. Boss 盲注不能被跳过, 但可以通过以下方式规避:

- 优惠券导演剪辑版 (每个底注可重掷 1 次) 与 Retcon (无限重掷), 每次 $10. 底注为 8 的倍数时重掷必定得到 Showdown 盲注.
- 小丑牌摔跤手 (出售以禁用当前 Boss) 与奇科特 (禁用所有 Boss 的效果).
  被禁用后, The Wall 与 Violet Vessel 的分数要求回到 2 倍, The Needle 的分数要求不变.

## 标签 (Tag)

跳过小盲注或大盲注时, 会获得该位置标注的标签. 标签共 24 种.

| 标签 | 效果 | 可出现的底注 |
| --- | --- | --- |
| 不常见标签 (Uncommon Tag) | 商店出现一张免费的不常见小丑牌 | 任意 |
| 稀有标签 (Rare Tag) | 商店出现一张免费的稀有小丑牌 | 任意 |
| 负面标签 (Negative Tag) | 下一张基础版本的商店小丑牌免费并变成负面 | 2+ |
| 闪箔标签 (Foil Tag) | 下一张基础版本的商店小丑牌免费并变成闪箔 | 任意 |
| 全息标签 (Holographic Tag) | 下一张基础版本的商店小丑牌免费并变成全息 | 任意 |
| 多彩标签 (Polychrome Tag) | 下一张基础版本的商店小丑牌免费并变成多彩 | 任意 |
| 投资标签 (Investment Tag) | 击败 Boss 盲注后获得 $25 | 任意 |
| 凭证标签 (Voucher Tag) | 下一间商店多出一张优惠券 | 任意 |
| Boss 标签 (Boss Tag) | 重掷 Boss 盲注 | 任意 |
| 标准标签 (Standard Tag) | 送一个免费的巨型标准包 | 2+ |
| 魅力标签 (Charm Tag) | 送一个免费的巨型塔罗包 | 任意 |
| 流星标签 (Meteor Tag) | 送一个免费的巨型天体包 | 2+ |
| 小丑标签 (Buffoon Tag) | 送一个免费的巨型小丑包 | 2+ |
| 手巧标签 (Handy Tag) | 本局每打出过一手牌给 $1 | 2+ |
| 垃圾标签 (Garbage Tag) | 本局每有一次未使用的弃牌给 $1 | 2+ |
| 缥缈标签 (Ethereal Tag) | 送一个免费的幻灵包 | 2+ |
| 抵用券标签 (Coupon Tag) | 下一间商店的初始卡片与补充包免费 | 任意 |

| 轨道标签 (Orbital Tag) | 随机一个牌型 +3 级 | 2+ |
| 经济标签 (Economy Tag) | 金钱翻倍 (最多 $40) | 任意 |

标签的获得方式: 跳过小盲注或大盲注, 立体牌组每击败 Boss 盲注获得一个双倍标签,
以及出售健怡可乐得到一个免费的双倍标签. 双倍标签会把下一次获得的标签数量翻倍.

## 其他

- Boss 盲注的效果在计分顺序的最前面触发, 例如燧石 (基础分减半) 和手臂 (降级).
- 失效效果会影响计分, 手持效果与小丑牌的 "手持时" / "计分时" 效果, 但不影响独立小丑牌.
- 面朝下的牌在被选中时才会显示, 面对 "第一手背面朝上" 这类盲注, 牌型名称会显示为 `???` 直到打出.
