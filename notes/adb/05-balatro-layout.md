# Balatro 界面布局概览

具体的可点击坐标见 [pos/](pos/README.md), 这里只描述界面由哪些区域组成, 以及每个区域里有什么.

## 主游戏界面

分区:

| 区域 | 范围 | 内容 |
| --- | --- | --- |
| 左侧竖长面板 | x 334-703 | 盲注信息, 回合分数, 牌型与筹码倍率, 出牌/弃牌数, 金钱, 底注/回合, 按钮 |
| 中央牌桌 | x 760-1900, y 550-860 | 打出的牌 (上方) 与手牌 (下方) |
| 底部按钮行 | y 890-1020 | 出牌, 理牌 (点数/花色), 弃牌 |
| 顶部计数 | y 270-320 | 小丑槽计数 (左), 消耗品槽计数 (右) |
| 右侧 | x 1850-2050 | 牌堆与剩余牌数 |

左侧面板自上而下: 盲注名称条, 盲注图标与分数线, 回合分数, 当前牌型名称与级别, 筹码框与倍率框,
比赛信息按钮与出牌/弃牌数, 金钱, 选项按钮与底注/回合.

牌桌上方在出牌时显示打出的牌和漂浮的得分数字; 手牌在下方呈扇形排列, 选中会上浮.

## 结算界面

中央偏右的大块深色面板, 显示盲注名, 至少得分, 奖励. 任意位置点击继续.

## 提现界面

顶部橙色 "提现: $N" 按钮, 下方明细面板逐行列出收入来源.

## 商店界面

| 区域 | 范围 | 内容 |
| --- | --- | --- |
| 左侧 | x 330-1060 | SHOP 招牌, 回合分数, 牌型框, 出牌/弃牌数, 金钱, 底注/回合 |
| 左中按钮列 | x 822-1055 | 下一个回合 (红), 重掷 (绿, 含价格) |
| 上排货架 | x 1225-1595, y 408-635 | 2 个随机商品卡位 (Joker / 塔罗 / 星球 / 扑克 / 幻灵) |
| 下排货架 | x 1020-1730, y 723-995 | 优惠券位, 2 个补充包位 |
| 右侧 | x 1850-2050 | 牌堆与剩余牌数 |

价格标签在槽位上方. 商品需两步购买: 先选中, 再点浮出的 "购买" 按钮.

## 其他要点

- 界面元素之间没有留白很多, 点击点必须落在元素中心附近; 按钮变灰时颜色掩码检测会失效, 量坐标要在启用态做.
- 游戏没有 view 层级 (Love2D 渲染), `uiautomator dump` 会返回空, 所有定位只能靠截图.
- 数值字体里 `0` 带斜杠, 缩小后易误读为 `8`.
