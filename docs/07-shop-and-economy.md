# 商店与经济

## 商店的构成

击败任何一场盲注 (含 Boss 盲注) 后都能进入商店. 默认情况下商店有:

- **2 张随机卡**: 通常是 Joker, 也可能出现塔罗牌和星球牌. 生成权重为 Joker 20, 塔罗 4, 星球 4,
  换算成概率约 71.4% / 14.3% / 14.3%.
- **2 个补充包**. 一局中第一次进入商店时, 其中一个必定是普通小丑包 (Buffoon Pack).
- **1 张优惠券**. 优惠券在击败 Boss 盲注后更换, 重掷商店不会刷新它.

影响货架的效果:

- Magic Trick 优惠券: 商店可以出售扑克牌 (权重 4); Illusion 优惠券: 扑克牌可能带增强与版本.
- 幽灵牌组: 幻灵牌可以出现在商店 (权重 2).
- Tarot Merchant / Planet Merchant 及其升级版把塔罗 / 星球的权重提高到 9.6 / 32.
- Overstock / Overstock Plus 优惠券让随机卡位增加到 3 / 4 个, 购买 Overstock 时立即补满空位.
- Clearance Sale / Liquidation 使商品打 75% / 50% 折扣.
- 小丑牌 混沌小丑: 每间商店第一次重掷免费.

Joker 生成时的稀有度权重固定为普通 70%, 不常见 25%, 稀有 5%; 传奇不会出现在商店.

## 重掷

- 起始价 $5, 每重掷一次 +$1, 进入新的商店后重置为 $5.
- 重掷会替换掉商店里剩余的随机卡, 但不会刷新补充包和优惠券.
- Reroll Surplus 优惠券把起始价降到 $3, Reroll Glut 再降到 $1.
- D6 标签让下一间商店的重掷从 $0 开始; 闪存卡小丑每次重掷 +2 倍率.
- 重掷是随机的, 之前见过又被掷掉的卡有可能再次出现.

### 计算公式

```text
buy_cost   = (base_cost + edition_cost + inflation_cost) * discount_percent   (四舍五入, 0.5 向下取整)
sell_value = floor(buy_cost / 2)
```

- **版本价格**: 闪箔 +$2, 全息 +$3, 多彩 +$5, 负面 +$5.
- **折扣**: Clearance Sale 使 discount_percent = 0.75, Liquidation 使 discount_percent = 0.5.
  折扣同时会间接降低出售价.
- **特殊情况**: 通货膨胀挑战每次购买后所有商品 +$1; 天文学家小丑让星球牌与天体包免费;
  Coupon Tag 使下一间商店所有商品免费 (优惠券除外); 带租用贴纸的小丑牌购买价固定为 $1.
- **额外售价**: 蛋 (每回合 +$3 售价), 礼品卡 (每回合给所有小丑牌与消耗品 +$1 售价) 的加成只作用于出售价,
  在其余计算之后叠加, 且不受折扣优惠券影响.

## 金钱

### 收入

1. **盲注奖励**: 小盲注 $3, 大盲注 $4, Boss 盲注 $5, Showdown 盲注 $8.
   红赌注及以上小盲注无奖励; 被骨头先生救下的盲注不给奖励; 残酷挑战小与大盲注都没奖励.
2. **未使用的出牌**: 每次 $1 (绿牌组 $2; 煎蛋卷与疯狂世界不给).
3. **小丑牌的回合结束效果**与卡牌效果.
4. **投资标签**: 击败 Boss 盲注时额外 $25.
5. **利息**: 见下节.

其他直接给钱的效果: 买价出售小丑牌与消耗品, 黄金牌 (留手 $3), 金色蜡封 (计分时 $3),
幸运牌 (1/15 概率 $20), 节制 ($50 上限), 隐者 (金钱翻倍, $20 上限), 献祭 ($20),
以及大量经济类小丑牌 (名片, 专属车位, 邮寄返利, 交易卡, 无脸小丑, 火箭, 云 9, 卫星, 黄金小丑等).

### 利息

- 每回合结束时, 每持有 $5 获得 $1 利息, **每回合上限 $5**, 也就是超过 $25 的钱不产生额外利息.
- 种子资金优惠券把上限提高到 $10 ($50 以内有效), Money Tree 提高到 $20 ($100 以内有效).
- 去月球小丑每 $5 额外多给 $1 利息, 与上表叠加.
- 回合结束时才触发的小丑牌 (例如黄金小丑, 火箭) 不算入本回合利息;
  手牌中的黄金牌与回合结束前触发的小丑牌 (例如专属车位) 算入本回合利息.
- 绿牌组, 煎蛋卷与疯狂世界挑战完全没有利息, 相关小丑与优惠券在这些情况下失效.

利息上限速查 (每回合能拿到的最大利息):

| 优惠券情况 | 恰好拿满利息所需金钱 | 每回合最大利息 |
| --- | --- | --- |
| 无 | $25 | $5 |
| 种子资金 | $50 | $10 |
| 种子资金 + Money Tree | $100 | $20 |
| 无, 但有一张去月球 | $25 | $10 |
| 种子资金, 但有一张去月球 | $50 | $20 |
| 种子资金 + Money Tree, 但有一张去月球 | $100 | $40 |

去月球提供的额外利息不受基础上限限制, 因此相当于把上限翻倍.

### 支出与负债

- 商店购买, 重掷, 补充包与优惠券.
- 租用小丑牌每回合结束 -$3.
- 信用卡小丑允许金钱降到 -$20, 即可以欠债消费.
