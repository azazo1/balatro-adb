# 牌组, 赌注与挑战

## 牌组 (Deck, 15 种)

牌组决定一局的初始状态. 一个牌组可以搭配任意赌注难度.

| 牌组 | 效果 | 解锁条件 |
| --- | --- | --- |
| 红牌组 (Red Deck) | 每回合 +1 次弃牌 | 初始可用 |
| 蓝牌组 (Blue Deck) | 每回合 +1 次出牌 | 收藏中发现 20 个条目 |
| 黄牌组 (Yellow Deck) | 起始金钱 +$10 | 收藏中发现 50 个条目 |
| 绿牌组 (Green Deck) | 回合结束: 每次剩余出牌 $2, 每次剩余弃牌 $1; 没有利息 | 收藏中发现 75 个条目 |
| 黑牌组 (Black Deck) | +1 小丑槽, 每回合 -1 次出牌 | 收藏中发现 100 个条目 |
| 魔术牌组 (Magic Deck) | 开局携带水晶球优惠券与 2 张愚者 | 用红牌组在任意难度通关 |
| 星云牌组 (Nebula Deck) | 开局携带望远镜优惠券, -1 消耗品槽 | 用蓝牌组在任意难度通关 |
| 幽灵牌组 (Ghost Deck) | 幻灵牌可能出现在商店, 开局携带咒怨 | 用黄牌组在任意难度通关 |
| 废弃牌组 (Abandoned Deck) | 牌组中没有点数牌 (J/Q/K) | 用绿牌组在任意难度通关 |
| 棋盘牌组 (Checkered Deck) | 初始牌组为 26 张黑桃与 26 张红桃 | 用黑牌组在任意难度通关 |
| 黄道牌组 (Zodiac Deck) | 开局携带塔罗商人, 星球商人与超量库存优惠券 | 在红赌注或更高难度用任意牌组通关 |
| 彩绘牌组 (Painted Deck) | +2 手牌上限, -1 小丑槽 | 在绿赌注或更高难度用任意牌组通关 |
| 立体牌组 (Anaglyph Deck) | 每击败一个 Boss 盲注获得一个 Double Tag | 在黑赌注或更高难度用任意牌组通关 |
| 等离子牌组 (Plasma Deck) | 计分时平衡筹码与倍率, 盲注分数要求 X2 | 在蓝赌注或更高难度用任意牌组通关 |
| 不稳牌组 (Erratic Deck) | 牌组中所有牌的点数与花色都随机化 | 在橙赌注或更高难度用任意牌组通关 |

## 赌注 (Stake, 8 个难度)

赌注是同一牌组上叠加的难度等级, 每提高一级都会保留之前所有效果.

| 赌注 | 效果 | 通关后解锁的牌组 |
| --- | --- | --- |
| 白赌注 (White) | 基础难度 | - |
| 红赌注 (Red) | 小盲注不再给奖励金钱 | 黄道牌组 |
| 绿赌注 (Green) | 分数要求随底注上升得更快 | 彩绘牌组 |
| 黑赌注 (Black) | 商店中可能出现永恒小丑牌 (不能出售或摧毁) | 立体牌组 |
| 蓝赌注 (Blue) | -1 次弃牌 | 等离子牌组 |
| 紫赌注 (Purple) | 分数要求进一步加快上升 | - |
| 橙赌注 (Orange) | 商店中可能出现易腐小丑牌 (5 回合后失效) | 不稳牌组 |
| 金赌注 (Gold) | 商店中可能出现租用小丑牌 (每回合 -$3) | - |

绿赌注与紫赌注会提高每个底注的基础分数要求, 具体数值见 [盲注与标签](08-blinds-and-tags.md).

## 挑战 (Challenge, 20 个)

挑战模式使用固定牌组与规则变异, 不能自选牌组和赌注.

| 挑战 | 规则变异 | 初始携带 | 牌组与限制 |
| --- | --- | --- | --- |
| 煎蛋卷 (The Omelette) | 所有盲注不给奖励钱, 剩余出牌不给钱, 没有利息 | 5 张蛋 | 标准 52 张; 禁用优惠券 Seed Money, Money Tree; 禁用小丑牌 To the Moon, Rocket, Golden Joker, Satellite |
| 15 分钟城市 (15 Minute City) | - | 永恒版坐公交, 永恒版捷径 | 每种人头牌各 2 张, 没有 A, 2, 3 |
| 富者愈富 (Rich get Richer) | 筹码不能超过当前金钱; 起始 $100 | Seed Money, Money Tree | 标准 52 张 |
| 刀锋边缘 (On a Knife's Edge) | - | 永恒且被钉住的仪式匕首 (始终在最左侧) | 标准 52 张 |
| X 光视力 (X-ray Vision) | 1/4 的牌以背面朝上的方式抽到 | - | 标准 52 张 |
| 疯狂世界 (Mad World) | 剩余出牌不给钱, 没有利息 | 永恒负面版空想性错视, 永恒版名片 | 只有 2 到 9, 共 32 张; 禁用盲注 The Plant |
| 奢侈税 (Luxury Tax) | 每持有 $5 手牌上限 -1, 初始手牌上限 10 | - | 标准 52 张 |
| 不会腐坏 (Non-Perishable) | 所有小丑牌都是永恒 | - | 标准 52 张; 禁用会自毁的小丑牌 (大香蕉, 卡文迪什, 冰淇淋, 龟豆, 拉面, 健怡可乐, 苏打水, 爆米花, 骨头先生, 隐形小丑, 摔跤手) 与盲注 Verdant Leaf |
| 美杜莎 (Medusa) | - | 永恒版大理石小丑 | 52 张, 所有人头牌替换为石头牌 |
| 孤注一掷 (Double or Nothing) | 所有打出的牌计分后失效 | - | 标准 52 张, 全部带红色蜡封 |
| 类型转换 (Typecast) | 击败底注 4 的 Boss 后: 所有小丑牌变为永恒, 小丑槽变为 0 | - | 标准 52 张; 禁用盲注 Verdant Leaf |
| 通货膨胀 (Inflation) | 每次购买后所有商品价格永久 +$1 | 信用卡 | 标准 52 张; 禁用优惠券 Clearance Sale, Liquidation |
| 布拉姆扑克 (Bram Poker) | 商店不再出现小丑牌 | 永恒版吸血鬼, 皇帝, 皇后, 魔术技巧, 幻象 | 标准 52 张 |
| 脆弱 (Fragile) | - | 2 张永恒负面版全是 6 | 标准 52 张, 全部为玻璃牌; 禁用一切能加入非玻璃牌或移除玻璃增强的途径 |
| 巨石 (Monolith) | - | 永恒版方尖碑, 永恒负面版大理石小丑 | 标准 52 张 |
| 发射升空 (Blast Off) | 每回合 2 次出牌, 2 次弃牌, 4 个小丑槽 | 永恒版星座, 永恒版火箭, 星球商人, 星球大亨 | 标准 52 张; 禁用优惠券 Grabber, Nacho Tong 与小丑牌窃贼 |
| 五张牌抽牌 (Five-Card Draw) | 每回合 6 次弃牌, 手牌上限 5, 7 个小丑槽 | 老千, 小丑 | 标准 52 张; 禁用提升手牌上限的小丑牌 (杂耍者, 吟游诗人, 龟豆) |
| 金针 (Golden Needle) | 每次弃牌花 $1, 每回合 1 次出牌, 6 次弃牌, 起始 $10 | 信用卡 | 标准 52 张; 禁用窃贼与优惠券 Grabber, Nacho Tong |
| 残酷 (Cruelty) | 小盲注与大盲注都不给奖励金钱, 3 个小丑槽 | - | 标准 52 张 |
| 无小丑 (Jokerless) | 商店不再出现小丑牌, 0 个小丑槽 | - | 标准 52 张; 禁用一切获得小丑牌的途径 (审判, 幽灵, 灵魂, 各类小丑标签, 小丑包, 反物质优惠券等) |

## 收藏 (Collection)

收藏界面记录所有见过的小丑牌, 消耗品, 优惠券, 补充包, 盲注与牌组, 并提供解锁进度.
牌组解锁条件中 "收藏中发现 N 个条目" 即指收藏界面的已发现数量.
