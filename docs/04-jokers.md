# 小丑牌

小丑牌 (Joker) 是 Balatro 的核心, 它们不进牌组也不参与出牌, 而是放在专门的小丑槽里持续提供效果:
加分, 给钱, 生成消耗品, 复制其他小丑牌, 改变规则等.

## 基本规则

- 当前版本共有 **150 张**小丑牌, 其中 105 张在第一次游戏时就可用, 其余 45 张需要通过特定条件解锁.
- 默认有 **5 个小丑槽** (黑牌组 6 个, 彩绘牌组 4 个, 五张牌抽牌挑战 7 个). 负面版本每张 +1 槽.
  槽位满了就不能再拿新的小丑牌, 除非卖掉或摧毁已有的.
- 稀有度与出现权重:

  | 稀有度 | 数量 | 商店中随机生成的概率 |
  | --- | --- | --- |
  | 普通 (Common) | 61 | 70% |
  | 不常见 (Uncommon) | 64 | 25% |
  | 稀有 (Rare) | 20 | 5% |
  | 传奇 (Legendary) | 5 | 不会在商店出现, 只能通过幻灵牌 "灵魂" 获得 (灵魂在天体/塔罗包中出现的概率为 0.3%) |

- 购买价参考区间: 普通 $1-$6, 不常见 $4-$8, 稀有 $7-$10, 传奇 $20 (实际上无法购买).
  出售价 = 购买价除以 2 向下取整, 再叠加 Egg / Gift Card 等额外售价加成.
- 小丑牌可以带上版本 (闪箔 / 全息 / 多彩 / 负面) 与贴纸 (永恒 / 易腐 / 租用), 详见 [卡牌修饰](03-card-modifiers.md).
- 通关后, 当时携带的小丑牌会得到该赌注颜色的贴纸, 只是外观记录.

## 触发类型

小丑牌的能力按触发时机分类, 顺序决定了它们的结算先后:

| 类型 | 触发时机 | 例子 |
| --- | --- | --- |
| 出牌时 (On Played) | 打出手牌的瞬间, 计分之前 | 绿色小丑的成长, DNA, To Do List |
| 计分时 (On Scored) | 每张参与计分的牌 | 贪婪小丑, 孤独托德, 照片 |
| 手持时 (On Held) | 留在手中的牌 | 举拳, 男爵, 专属车位 |
| 独立 (Independent) | 所有牌计分完成后 | 小丑牌 (+4 倍率), 旗帜, 钢铁小丑 |
| 依赖其他小丑牌 (On Other Jokers) | 独立阶段中 | 棒球卡 |
| 弃牌时 (On Discard) | 弃掉指定牌时 | 烧焦小丑, 邮寄返利 |
| 混合 (Mixed) | 跨多个阶段 | 跑者 (成长在出牌时, 加筹码在独立阶段) |
| 选择盲注时 (On Blind Select) | 选择盲注时, 跳过盲注不触发 | 乌合之众, 纸牌占卜师 |
| 被动 (N/A) | 不做具体触发 | 黄金小丑, 四指 |

要点:

- 复制类小丑牌 Blueprint (复制右侧) 和 Brainstorm (复制最左侧) 只能复制会真正触发的效果, 被动类复制不到;
  它们也不会复制 "选择盲注时" 之外的其他类型以外的时机不匹配的效果.
- 同一张牌触发多个同类型小丑牌时, 一律按小丑牌从左到右的顺序触发.
- 摆位技巧: 同类型效果中, 先加算倍率再乘算倍率分数更高, 例如把 Joker (+4 倍率) 放在 Ramen (X2 倍率) 左边.
- 复制产生的小丑牌会去掉负面版本 (不额外提供槽位).
