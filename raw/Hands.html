Hands can be used to play a certain Poker Hand during a round to gain score and beat blinds. A run will fail if all hands in one round are used while the score requirement is not met.

Most decks start each run with 4 hands per round. Note that the player will always start each round with at least 1 hand, even when combining effects that would reduce the amount of hands to 0 or lower.

If the player finishes a round with some hands leftover, by default, they will gain $1 for each remaining hand in the Cash Out screen. Increasing Hands

[edit | edit source]

Decks

[edit | edit source]
  • ( {{hl|blue|+1}} hand every round Discover at least {{hl|orange|20}} items from your [[collection]] Blue Deck.png) Blue Deck provides +1 hand every round.

Jokers

[edit | edit source]
  • (When [[Blind|{{hl|orange|Blind}}]] is selected, gain {{hl|blue|+3}} Hands and {{hl|orange|lose all discards}} Uncommon Effect On Blind Select Burglar.png) Burglar provides +3 hands each round.

Vouchers

[edit | edit source]
  • The (Permanently gain {{hl|blue|+1}} hand per round Base Grabber.png) Grabber and (Permanently gain an additional {{hl|blue|+1}} hand per round Play a total of 2,500 cards Upgraded Nacho Tong.png) Nacho Tong Vouchers each add 1 hand.

First hand triggers

[edit | edit source]

The following Jokers and Blinds only trigger on first hand played.

Jokers

[edit | edit source]
  • (If {{hl|orange|first hand}} of round has only {{hl|orange|1}} card, add a permanent copy to deck and draw it to {{hl|orange|hand}} Rare Effect On Played DNA.png) DNA creates a permanent copy of a selected playing card if first hand in round contains only 1 card.
  • (If {{hl|orange|first hand}} of round is a single {{hl|orange|6}}, destroy it and create a {{Spectral|}} card <br> {{room}} Uncommon Effect N/A (Passive) Sixth_Sense.png) Sixth Sense creates a Spectral card and destroys the selected playing card if first hand contains a single playing card with a rank of 6.

Blinds

[edit | edit source]
  • ( Boss The Mouth.webp) The Mouth forces the player to keep playing the first hand type they played in the round.

Final hand triggers

[edit | edit source]

These Jokers trigger when the player's hand count is 1 and/or facing ( Boss The Needle.webp) The Needle in most cases.

Jokers

[edit | edit source]
  • ({{xmult|3}} on {{hl|orange|final hand}} of round Play {{hl|orange|200}} hands Uncommon Multiplicative Mult Independent Acrobat.png) Acrobat gives X3 Mult on final hand.
  • (Retrigger all played cards in {{hl|orange|final hand}} of the round Uncommon Retrigger On Scored Dusk.png) Dusk retriggers all playing cards on final hand.

Synergies

[edit | edit source]

Jokers

[edit | edit source]
  • All Jokers that scale upon hand played, such as (Adds the number of times [[Poker Hands|{{hl|orange|poker hand}}]] has been played this run to Mult Common Additive Mult Independent Supernova.png) Supernova, (This Joker gains {{Mult|+1}} per {{hl|orange|consecutive}} hand played without a scoring {{hl|orange|face}} card <br> {{Currently|{{Mult|+0}}}} Common Additive Mult Mixed Ride the Bus.png) Ride the Bus, ({{mult|+1}} per hand played <br> {{mult|-1}} per discard <br> {{Currently|{{mult|+0}}}} Common Additive Mult Mixed Green_Joker.png) Green Joker, (This Joker gains {{Chips|+4}} if played hand has exactly {{hl|orange|4}} cards <br> {{Currently|{{Chips|0}}}} Common Chips Mixed Square_Joker.png) Square Joker, and (This Joker gains {{Chips|+8}} when each played {{hl|orange|2}} is scored <br> {{Currently|{{chips|+0}}}} Win a run in {{hl|orange|18}} or fewer rounds Rare Chips Mixed Wee Joker.png) Wee Joker, scale with more hands played.
  • ({{hl|green|1 in 4}} chance to upgrade level of played [[Poker hands|{{hl|orange|poker hand}}]] Uncommon Effect On Played Space Joker.png) Space Joker has more opportunities to activate with more hands.
  • ({{xmult|3}} if played {{hl|orange|poker hand}} has already been played this round Uncommon Multiplicative Mult Independent Card_Sharp.png) Card Sharp can activate more times with more hands.
  • ({{xmult|4}} every {{hl|orange|6}} hands played<br>{{hl|grey|5 remaining}} Uncommon Multiplicative Mult Independent Loyalty Card.png) Loyalty Card becomes easier to activate with more hands.

Tags

[edit | edit source]
  • ( Handy tag.png) Handy Tag gives more money the more hands are played.
